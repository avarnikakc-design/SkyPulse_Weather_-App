# ⛅ SkyPulse Weather Telemetry App

A sleek, responsive weather telemetry application designed to fetch and display real-time global weather conditions through asynchronous REST API integration.

---

## ✨ Features

* **Live City Search:** Search for current weather metrics across global locations in real time.
* **Atmospheric Telemetry:** Displays temperature, humidity, wind speed, and weather descriptions cleanly.
* **Error Handling:** Gracefully handles invalid location queries or network failures with clear UI feedback.
* **Dark-Mode Aesthetic:** Modern, high-contrast dark dashboard layout optimized for clear data visualization.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (Async/Await, Fetch API)
* **API:** OpenWeatherMap API / Weather Telemetry endpoints
* **Icons:** FontAwesome
